# zxporter-nodemon

![Type: application](https://img.shields.io/badge/Type-application-informational?style=flat-square)

A Helm chart for Kubernetes

zxporter-nodemon is the per-node DaemonSet that collects container, GPU (DCGM)
and runtime metrics for zxporter. It is normally installed as a subchart of
`zxporter`; installing it on its own is for testing.

Every object carries `app.kubernetes.io/part-of: dz-platform` and a
`devzero.io/component` label naming its chart, from the shared
`devzero-common` library. Pod templates and selectors do not carry them.

To pull from a private registry, set `global.imageRegistry` (the `dz-platform`
umbrella sets it for every component, and `zxporter` passes its globals to
this subchart). It replaces the registry host of the nodemon and DCGM exporter
images and keeps the path, tag and digest:
`public.ecr.aws/devzeroinc/zxporter-nodemon:<tag>` becomes
`<global.imageRegistry>/devzeroinc/zxporter-nodemon:<tag>`. The value may
carry a path prefix (`harbor.example/devzero`). `global.imagePullSecrets` is
merged with `imagePullSecrets` on every nodemon pod; both take names or
`{name: ...}` objects.

The chart vendors its dependencies into `charts/`, which is not committed.
From a source checkout, run `make helm-deps` (or `helm dependency build` on
the chart) before installing or rendering it.

This README is generated by [helm-docs](https://github.com/norwoodj/helm-docs)
from `values.yaml` and `README.md.gotmpl`; edit those and run
`just chart-docs` in the DevZero services monorepo instead of editing it.
